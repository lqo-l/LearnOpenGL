# 背面剔除

## opengl api
```c++
glEnable(GL_CULL_FACE);
glCullFace(GL_BACK); // 剔除背面
glFrontFace(GL_CCW); // 逆时针为正，此时剔除背面即剔除顺时针

```

## 地板三角形的朝向
```c++
float planeVertices[] = {
    5.0f, -0.5f,  5.0f,  
    -5.0f, -0.5f, -5.0f, 
    -5.0f, -0.5f,  5.0f,

    5.0f, -0.5f,  5.0f, 
    5.0f, -0.5f, -5.0f,  
    -5.0f, -0.5f, -5.0f, 
};
```
xz平面上的三角形，(5,5)->(-5,-5)->(-5,5) 定义了一个从上向下看的逆时针的三角形，因此从上向下能看到。注意xz平面从上向下看时，x向右，z向下。

> 从正面看是顺时针，则从背面看是逆时针。
