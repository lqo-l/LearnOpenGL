通常获取的值都是在sRGB空间的（已经开2.2次方了），不需要其他校正处理就可以直接丢给显示器了。
但sRGB的纹理在做光照计算时，应该转回线性（pow2.2次方）

这里默认转回线性，三个mode代表：
mode1： 不转回sRGB
mode2： opengl的转回sRGB
mode3： 手动的转回sRGB

对应的衰减处理： 转回线性空间后应该使用平方级衰减，更符合物理。原来没有gamma校正时使用线性衰减更合适，因为线性的衰减在显示器显示时进行2.2次方后正好是平方级的，碰巧符合物理。现在进行了gamma校正开2.2次方就应该使用正确的平方级处理了。

或者读取sRGB纹理时直接用sRGB格式去glTexImage2D加载
