## 模型矩阵
Model = T(RS)  // 平移前，模型中心在世界坐标原点，相对于原点缩放和旋转。后进行平移。

## 视图矩阵
定义front为相机朝向，视图坐标系的z为-front。
right为相机右方向，x轴； up为相机上方，y轴。

则：
View = (TR)^{-1} = T^{-1}R^{-1}  其中T和R均为相机相对于世界坐标系的平移和旋转
T即相机位置
R通过三列基向量构造得到(right,up,-front)，其中
- front为朝向，应为已知值
- right = cross((0,1,0), -front)
- up = cross(-front, right)
